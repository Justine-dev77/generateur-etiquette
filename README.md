## ✨ Fonctionnalités

- 📝 **Texte libre** : écris ce que tu souhaites sur ton étiquette.
- 🦇 **Typographies au choix** : classique, metal et styles horrifiques.
- 🎨 **Huit couleurs de cadre** : noir, rose, violet, bleu azur, rouge, vert, orange et bordeaux.
- 🖼️ **Image de fond personnalisée** : importe ton propre visuel ou conserve le fond blanc.
- 📏 **Taille ajustable** : choisis une largeur de 300 à 800 px.
- 👁️ **Aperçu en direct** : visualise le résultat avant de l'enregistrer.
- 💾 **Téléchargement PNG** : exporte ton étiquette avec un extérieur transparent.
- 🔄 **Réinitialisation rapide** : reviens aux réglages de départ.

## 🪄 Comment l'utiliser ?

1. **[Ouvre le générateur](https://justine-dev77.github.io/generateur-etiquette/)**.
2. Saisis ton texte et sélectionne la typographie.
3. Choisis la couleur du cadre, et ajoute une image de fond si tu le souhaites.
4. Ajuste la taille et regarde l'aperçu.
5. Clique sur **« Télécharger PNG »**.

## 🛠️ Technologies

Ce projet fonctionne directement dans le navigateur, sans installation :

- **HTML5** pour la structure ;
- **CSS3** pour l'interface sombre ;
- **JavaScript** et **Canvas** pour créer et télécharger les étiquettes ;
- **GitHub Pages** pour l'hébergement.
